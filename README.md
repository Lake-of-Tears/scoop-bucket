# Lake of Tears Scoop Bucket 🍨

Official [Scoop](https://scoop.sh/) bucket for Lake of Tears developer tools and CLIs.

---

## Installation

Add this bucket to Scoop and install `angler`:

```powershell
# 1. Add the bucket
scoop bucket add lake-of-tears https://github.com/Lake-of-Tears/scoop-bucket

# 2. Install angler
scoop install angler
```

---

## Upgrades

Keep `angler` updated:

```powershell
scoop update angler
```

---

## Verification

```powershell
angler version
angler --help
```
